# ROS2Blinka
An API Library for CircuitPython Blinka on Robot Operating System 2

First written on `ros2-lyrical`, source-built on Raspberry Pi OS Trixie.

## Compatibility
Operating System: Debian-core Linux based on Trixie or newer
ROS2: Lyrical or newer

## Installation
1. Install the latest stable ROS 2 Distribution, using their instructions for the Linux distribution of choice.
2. While sourced for ROS 2, Install Adafruit Blinka.
3. Clone this repository using `git clone`
